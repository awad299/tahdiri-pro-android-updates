# Tahdiri Pro Android Updates

Binary-only Android update channel for Tahdiri Pro. The application source code is kept in the private main repository. Do not place credentials, tokens, or source code in this repository.

## Channels
- `latest.json`: legacy Gecko / `sa.tahdiripro.mobile.pilot2` channel. Kept separate so existing Gecko installations never receive an incompatible package.
- `latest-lite.json`: official WebView Lite / `sa.tahdiripro.mobile.litepilot` channel. Current stable baseline: **Lite28 / versionCode 11528** (Smart Live PASS).
